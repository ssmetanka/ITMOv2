# Requirements: AI-Review API

## Фича A: Входная валидация diff
1. Входной diff не должен превышать 300 строк или 10 000 символов.
2. При превышении лимита запрос немедленно отклоняется с ошибкой ValueError("Diff too large").
3. При отклонении по валидации вызов внешней LLM категорически запрещён.

## Фича B: Обработка ошибок зависимости (LLM Timeout)
1. Вызов LLM ограничен строгим таймаутом (2.0 секунды).
2. При превышении времени ожидания или сбое сети сервис возвращает понятную ошибку RuntimeError("LLM service unavailable or timed out").
3. Поведение и тесты фичи A должны полностью сохраняться.
