# Style Guide проекта

1. **Публичный интерфейс:** Проверяй поведение сервиса через вызовы публичных методов API, а не приватных функций.
2. **Типизация:** Обязательно используй аннотации типов Python (`typing`).
3. **Минимум внешних зависимостей:** Не подключай тяжелые библиотеки ради элементарной валидации.
4. **Не ослабляй runner:** Запрещено отключать падающие тесты ради зелёного статуса.
